## Где это публикуется

Битрикс24 требует **рабочие ссылки в браузер** (HTML / PDF / TXT, не на скачивание). Поэтому документы нужно:

1. Сконвертировать в HTML или PDF.
2. Разместить на корпоративном домене (например, `https://<vendor-domain>.ru/legal/eula`, `…/privacy`, `…/pdn-consent`).
3. Указать ссылки в карточке решения:
   - «Использовать своё лицензионное соглашение» → URL EULA.
   - «Использовать свою политику конфиденциальности» → URL privacy-policy.

## Привязка к названию приложения

Лицензионное соглашение **обязано** содержать **точное название приложения** (см. `copy.md` пункт 1). Если название поменяется до первой модерации — обновить EULA одновременно.
