## US-3. Голосование

| US | Описание | Endpoint / Файл | Статус |
|----|----------|-----------------|--------|
| US-3.1 | Согласующий видит сообщение бота с кнопками | `bot/messages.build_approval_message` + `bot/keyboard.py` | ✅ |
| US-3.2 | Согласующий нажимает «Согласовать» / «Отклонить» | `views.vote_handle` | ✅ |
| US-3.3 | Голос сохраняется в `approval_votes` | `b24_client.add_vote` | ✅ |
| US-3.4 | Дублирующий клик не приводит к двойному голосу | `services.handle_vote` race-protection (Sprint 2.1) | ✅ |
| US-3.5 | Сообщение бота обновляется с новыми результатами | `imbot.message.update` | ✅ |
| US-3.6 | Инициатор не может голосовать | `rules.validate_can_vote:19-20` | ✅ |
| US-3.7 | Не-согласующий не может голосовать | `rules.validate_can_vote:27-28` | ✅ |
| US-3.8 | Голосовать нельзя после завершения запроса | `rules.validate_can_vote:15-17` | ✅ |
| US-3.9 | Согласующий видит подтверждение «Ваш голос учтён» | `views._answer_vote_command:316-317` | ✅ |
| US-3.10 | Согласующий может изменить голос | `services.handle_vote` (last vote wins) | 🟡 (работает на уровне rules, но добавляет новую запись — нет UPDATE) |

**Покрытие US-3**: 9/10 = 90%

## Приоритетные пробелы

1. **US-1.4** `ONAPPUNINSTALL` — критично для GDPR/удаления данных при деинсталляции (Sprint 2.2).
2. **US-7.2** Проверка прав на просмотр запроса — security (Sprint 2.2).
3. **US-2.7** UI для `bot_issue` — UX (Sprint 2.1+).
4. **US-4.4** Решить судьбу `EXPIRED` — либо удалить из доки, либо реализовать (Sprint 2.3).
5. **US-6.2/3** Уведомления инициатору и напоминания — backlog (после Sprint 4).
