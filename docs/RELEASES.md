## Версия в ветке `claude/tech-debt` — 02.10.2026 (не выкачена)

Релиз без новых функций: исправления и приведение к обещанному в карточке Маркета.

- **Правило «Большинство» работает как большинство.** Раньше один отказ закрывал запрос при любом правиле. Теперь запрос отклоняется, только когда набрать больше половины голосов «за» уже нельзя. Пример: трое согласующих, один отказал — двое оставшихся ещё могут согласовать.
- **Не больше 10 согласующих в запросе.** Лимит был заявлен, но не проверялся.
- **Себя нельзя выбрать согласующим.** Инициатор не голосует, и запрос с ним в списке при правиле «Единогласно» не мог завершиться.
- **Длинные списки.** «Мои запросы» и «Входящие» открываются по 20 записей с кнопкой «Показать ещё». Раньше согласующий видел только запросы из последних 50 на портале.
- **Списки открываются быстрее.** Журнал и ссылки на файлы подгружаются при раскрытии карточки.
- **Защита от голосования за другого.** Сервер проверяет у портала, кому принадлежит авторизация, и при входе, и при нажатии кнопки.

## Версия в Маркете — опубликована

### Описание

**Приложение для согласований в чате** — версия, прошедшая модерацию и опубликованная в Маркете Битрикс24. Ниже — что она умеет фактически.

### Функциональность

#### ✅ Создание запроса согласования
- Инициатор создаёт запрос из любого чата, используя размещение `IM_TEXTAREA`.
- Заполняет обязательные поля:
  - **Комментарий**: описание запроса.
  - **Список согласующих**: выбор одного или нескольких сотрудников.
  - **Правило согласования**: «Все согласующие» (единогласно) или «Большинство» (больше половины).
- Опционально: до 10 файлов по 25 МиБ; они загружаются на Диск портала.
- Нажимает кнопку «Создать запрос» — приложение проверяет данные и публикует запрос в чат.

#### ✅ Голосование согласующих
- Бот присылает каждому согласующему личное сообщение с кнопками:
  - **Одобрить** — согласующий поддерживает запрос.
  - **Отклонить** — согласующий против.
- Проголосовать можно один раз, изменить решение нельзя.
- После каждого голоса сообщения у всех согласующих обновляются: видно, кто согласовал, кто отклонил и кого ждут.
- Инициатору бот пишет о каждом голосе.
- В исходный чат бот ничего не публикует.

#### ✅ Автоматическое определение статуса
- После каждого голоса приложение пересчитывает статус:
  - **Одобрено** — согласовали все (правило «Все согласующие») или больше половины (правило «Большинство»).
  - **Отклонено** — в опубликованной версии: хотя бы один согласующий отклонил, при любом правиле.
  - **Сбор голосов** — решения ещё нет.
  - **Отменено** — инициатор отменил запрос.

#### ✅ Вложения
- К запросу можно приложить до 10 файлов.
- Файлы загружаются в папку «Согласования» на общем диске портала, по подпапке на запрос.
- Ссылки на файлы есть в сообщении бота и в карточке запроса.

#### ✅ История событий
- Каждый запрос ведёт полный журнал событий:
  - Создание запроса (инициатор, время, список согласующих).
  - Каждый голос (согласующий, решение, время).
  - Отмена запроса (инициатор, время).
  - Финальный статус и время заключения.
- История доступна в открытом окне деталей запроса или через меню "История" в карточке.

#### ✅ Управление запросами
- **Для инициатора**:
  - Вкладка "Мои запросы" — список всех запросов, созданных пользователем.
  - Возможность отменить активный запрос (кнопка "Отменить").
  - Просмотр статуса и истории.
- **Для согласующего**:
  - Вкладка "Входящие" — список запросов, в которых пользователь согласующий.
  - Голосование — кнопками в сообщении бота; в списке кнопок нет.

#### ✅ Интеграция с Bitrix24
- Приложение работает нативно в чатах Bitrix24.
- Использует Bitrix24 Disk для хранения вложений.
- Использует Bitrix24 Entity Storage для хранения данных запросов и голосов.
- Использует бот для публикации сообщений (не требует отдельной конфигурации).
- Поддерживает права доступа на уровне портала Bitrix24.

### Ограничения

- Результат не публикуется в исходный чат.
- У отказа нет причины: кнопка не собирает комментарий.
- Нет срока ответа и напоминаний.
- Нет делегирования и замены согласующего.
- Нет связи с бизнес-процессами, сделками и задачами.
- Нет выгрузки истории.

### Требования для установки

- Портал Битрикс24 на тарифе «Стандарт» и выше (так указано в манифесте приложения).
- Права администратора для установки приложения.
- Права: `im`, `imbot`, `entity`, `disk`, `placement`, `user_basic`, `mobile`.

### Как начать

1. Администратор Bitrix24 устанавливает приложение из Маркетплейса (поиск "Согласования в чате").
2. Приложение автоматически инициализируется (создаёт хранилище, регистрирует бота).
3. Сотрудники могут сразу начать создавать запросы из любого чата.

### Технические детали

- **Frontend**: Nuxt 4, Vue 3, TypeScript.
- **Backend**: Python 3.11 + Django (serverless-модель, без собственной БД).
- **Хранилище**: хранилище приложения на портале (`appr_requests`, `approval_votes`, `appr_events`).
- **Инфраструктура**: Docker, Docker Compose.
