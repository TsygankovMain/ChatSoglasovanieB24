## [Current MVP / 0.1.0] — Готовится к публикации

### Описание

**Приложение для согласований в чате** — первая версия приложения, реализующая упрощённый процесс согласования прямо в Bitrix24 чате.

### Функциональность

#### ✅ Создание запроса согласования
- Инициатор создаёт запрос из любого чата, используя размещение `IM_TEXTAREA`.
- Заполняет обязательные поля:
  - **Комментарий**: описание запроса.
  - **Список согласующих**: выбор одного или нескольких сотрудников.
  - **Правило согласования**: требуется ли единогласие ("Все должны согласиться") или достаточно большинства ("Один голос за — достаточно").
- Опционально: прикрепление файла из Bitrix24.Disk.
- Нажимает кнопку «Создать запрос» — приложение проверяет данные и публикует запрос в чат.

#### ✅ Голосование согласующих
- Бот публикует сообщение в чате с кнопками:
  - **Согласовать** (Approve) — согласующий поддерживает запрос.
  - **Отклонить** (Reject) — согласующий против запроса.
  - **Запросить уточнение** — согласующий хочет дополнительной информации (статус запроса приостанавливается).
- Каждый согласующий может нажать кнопку один раз; повторный клик перезаписывает его голос.
- Статус обновляется в реальном времени — участники видят актуальное количество голосов.

#### ✅ Автоматическое определение статуса
- После каждого голоса приложение пересчитывает статус:
  - **Одобрено** (APPROVED) — все согласующие нажали "Согласовать" (при условии достаточного правила).
  - **Отклонено** (REJECTED) — хотя бы один нажал "Отклонить" или "Запросить уточнение" (если нужно единогласие).
  - **В сборе голосов** (COLLECTING) — ещё не все согласующие голосовали.
  - **Отменено** (CANCELLED) — инициатор отменил запрос.
- Статус отображается в сообщении бота в виде значка (зелёный/красный) и текстового описания.

#### ✅ Вложения
- При создании запроса можно прикрепить один файл из Bitrix24.Disk.
- Файл загружается в автоматически созданную папку приложения на Диске.
- Сссылка на файл доступна в окне деталей запроса и в истории.

#### ✅ История событий
- Каждый запрос ведёт полный журнал событий:
  - Создание запроса (инициатор, время, список согласующих).
  - Каждый голос (согласующий, решение, время, комментарий если есть).
  - Отмена запроса (инициатор, время).
  - Финальный статус и время заключения.
- История доступна в открытом окне деталей запроса или через меню "История" в карточке.

#### ✅ Управление запросами
- **Для инициатора**:
  - Вкладка "Мои запросы" — список всех запросов, созданных пользователем.
  - Возможность отменить активный запрос (кнопка "Отменить").
  - Просмотр статуса и истории.
- **Для согласующего**:
  - Вкладка "Входящие" — список запросов, в которых пользователь согласующий.
  - Быстрое голосование прямо из списка (кнопки "Согласовать" / "Отклонить").

#### ✅ Интеграция с Bitrix24
- Приложение работает нативно в чатах Bitrix24.
- Использует Bitrix24 Disk для хранения вложений.
- Использует Bitrix24 Entity Storage для хранения данных запросов и голосов.
- Использует бот для публикации сообщений (не требует отдельной конфигурации).
- Поддерживает права доступа на уровне портала Bitrix24.

### Ограничения (известные)

- Таймаут запроса (автоматическое завершение по времени) — в планах следующей версии.
- Интеграция с Business Process (автоматические действия после согласования) — в планах.
- Экспорт истории согласований — в планах.
- Поддержка делегирования прав голосования — в планах.

### Требования для установки

- Портал Bitrix24 версии 2024 и выше.
- Права администратора для установки приложения.
- Скоупы: `im`, `imbot`, `entity`, `disk`, `placement`, `user`.
- Доступ в интернет для автоматических обновлений (опционально).

### Как начать

1. Администратор Bitrix24 устанавливает приложение из Маркетплейса (поиск "Согласования в чате").
2. Приложение автоматически инициализируется (создаёт хранилище, регистрирует бота).
3. Сотрудники могут сразу начать создавать запросы из любого чата.

### Технические детали

- **Frontend**: Vue 3 + Nuxt 3, современный TypeScript.
- **Backend**: Python 3.11 + Django (serverless-модель, без собственной БД).
- **Хранилище**: Bitrix24 Entity Storage (appr_requests, approval_votes).
- **Инфраструктура**: Docker, Docker Compose.
