# Дизайн-ассеты для Битрикс24 Маркетплейс

Базовый комплект исходников в SVG. Это **первая итерация** — сделана силами разработки, чтобы продакт мог идти к модерации, не ожидая дизайнера. После найма дизайнера он принимает эти файлы как baseline и улучшает по `docs/ru/marketplace/visuals-brief.md`.

## Содержимое

| Файл | Размер | Назначение |
|------|--------|------------|
| `icon-marketplace-512.svg` | 512×512 (vector) | Иконка приложения для карточки Маркетплейса |
| `icon-textarea-108x66.svg` | 108×66 (vector) | Иконка над полем ввода чата (`IM_TEXTAREA` placement) |
| `bot-avatar-200.svg` | 200×200 (vector) | Аватар бота, передаётся в `imbot.register` |
| `promo-banner-1920x800.svg` | 1920×800 (vector) | Промо-баннер для лендинга и соцсетей |
| `preview.html` | — | Открывается в браузере, показывает все ассеты + палитру + микро-копи |

## Как конвертировать в PNG для загрузки

Битрикс24 принимает только PNG/JPEG. Конвертация:

### macOS / Homebrew
```bash
brew install librsvg
rsvg-convert -w 512 icon-marketplace-512.svg -o icon-marketplace-512.png
rsvg-convert -w 108 -h 66 icon-textarea-108x66.svg -o icon-textarea-108x66.png
rsvg-convert -w 200 bot-avatar-200.svg -o bot-avatar-200.png
rsvg-convert -w 1920 promo-banner-1920x800.svg -o promo-banner-1920x800.png
```

### Inkscape (кроссплатформенно)
```bash
inkscape -w 512 icon-marketplace-512.svg -o icon-marketplace-512.png
```

### Web-конвертеры
- <https://cloudconvert.com/svg-to-png>
- <https://svgtopng.com/>

## Просмотр в браузере

```bash
# из корня репозитория
open assets/marketplace/preview.html      # macOS
xdg-open assets/marketplace/preview.html  # Linux
```

В preview-странице видно: палитру, все три иконки (с шахматным фоном для IM_TEXTAREA, чтобы был виден прозрачный фон), промо-баннер, таблицу скриншотов и финальный список файлов для отправки в Маркетплейс.

## Что осталось сделать дизайнеру

Эти SVG — функциональный baseline. Финальные ассеты **должны** быть улучшены по следующим направлениям:

1. **Иконка Маркетплейса** — добавить характер, рассмотреть варианты:
   - Чат-баббл с галочкой (текущий) — узнаваемо, но «сухо».
   - Две стрелки ↑↓ внутри чат-баббла — метафора голосования.
   - Стилизованное «рукопожатие» в чат-баббле — командное согласие.
2. **Аватар бота** — рассмотреть смягчение «робота» (антропоморфные черты лучше работают в B2B-чате).
3. **Промо-баннер** — заменить SVG-мокап чата на настоящий скриншот после рендера приложения дизайнером в Figma.
4. **Скриншоты приложения** — это отдельный поток: их делает QA в реальном Битрикс24 после рендера, потом дизайнер аннотирует.
5. **Видео-демо 30–60 сек** — сценарий в `docs/ru/marketplace/visuals-brief.md` пункт 6.
