Структура кода

Django-приложение и Nuxt-компоненты. Последний раздел дизайна.

🐍 Django (backends/python/api/)

backends/python/api/
├── approvals/ # новый Django app
│ ├── views.py # endpoints
│ ├── services.py # бизнес-логика
│ ├── rules.py # правила голосования
│ ├── b24_client.py # обёртка B24 REST
│ ├── serializers.py
│ └── urls.py
├── bot/ # Bot Platform 2.0
│ ├── handler.py # webhook handler
│ ├── messages.py # шаблоны сообщений
│ └── keyboard.py # кнопки (keyboard builder)
├── disk/
│ └── service.py # папки + загрузка файлов
├── config/
│ ├── settings.py
│ └── urls.py
└── core/
├── auth.py # JWT middleware
└── b24_entity.py # entity storage helpers
rules.py — ApprovalRules: can_vote(), is_approved(), is_rejected(). Изолированная логика, легко тестить.
b24_client.py — единственное место вызовов B24 REST API. Все остальные модули используют его.
keyboard.py — строит Bot Platform 2.0 keyboard JSON с кнопками Одобрить/Отклонить.

🖥️ Nuxt (frontend/app/)

frontend/app/
├── pages/
│ ├── index.client.vue # список запросов
│ └── handler/
│ └── placement-crm-deal-detail-tab.client.vue
├── components/
│ ├── approval/
│ │ ├── CreateForm.vue # форма (одна страница)
│ │ ├── RequestCard.vue # карточка запроса
│ │ ├── VoteStatus.vue # счётчики голосов
│ │ └── StatusBadge.vue # бейдж статуса
│ └── FileUploadArea.vue
├── composables/
│ ├── useApproval.ts # create, list, cancel
│ └── useFileUpload.ts # multipart upload
├── stores/
│ └── approvals.ts # Pinia store
└── locales/
├── ru.json
└── en.json
CreateForm.vue — B24UI компоненты: UInput, UTextarea, USelect (threshold), B24UserSelector, UButton. Mobile-first.
index.vue — список запросов инициатора + входящих согласований. Разные вкладки.
